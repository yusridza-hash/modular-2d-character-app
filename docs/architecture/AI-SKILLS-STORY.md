# Optional AI Tools & Story Continuity (static comics only)
AI is an interaction layer operating only through typed validated skills: character.segment, character.rig.suggest, expression.create/import, pose.apply, panel.compose, panel.check.continuity, asset.search. NO animation/video tools. AI must not bypass scene/asset validation or directly mutate arbitrary DB rows. Complex changes use propose→preview→approve→apply revision; rejected proposal creates no master mutation. Permissions, input/output schemas, error codes, idempotency and job logs required.
Story index stores chapters, pages, panels, characters, locations, chronological events and canonical character/scene states. Retrieval follows current panel and relevant IDs rather than sending full story. Deterministic editor actions do not require AI invocation. Memory is project data distinct from transient AI conversation. AI features optional and must not block manual comic workflow.
