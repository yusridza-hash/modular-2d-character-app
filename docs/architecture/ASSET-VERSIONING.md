# Asset Registry, Dependency, Revisions
Asset logical ID != immutable asset version ID. Source images, clean images, masks, sprites, rig, expression packs, poses, backgrounds, props, blend presets are versioned and addressable. Preserve input + parameters/model version + mask + outputs for reproducibility. Publish immutable revisions; drafts can be edited; published comic panels pin versions by default. No implicit update of old panels.
Store metadata/relationships in Supabase Postgres, large images in private Supabase Storage. Suggested objects: projects, assets, asset_versions, asset_dependencies, characters, character_views, rig_versions, face_expression_sets, poses, scene_instances, panels, pages, scene_revisions, jobs. Stable owner/project IDs and RLS; no service-role keys in browser.
Path convention: projects/{project_id}/assets/{asset_id}/versions/{version_id}/{filename}. Validate MIME, dimensions, checksum, file size. Download project bundle contains schema-versioned manifest and all referenced assets for portable restore. Soft-delete referenced assets until dependent published versions are resolved. Draft autosave + snapshots + recover on interruption. Add migration and schema evolution tests.
