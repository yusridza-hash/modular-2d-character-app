# Comic Page Editor, Templates and Publishing
## Page UX
Bottom panel/page thumbnail strip in normal Comic Editor; dedicated Page Layout mode when arranging panels, gutter and margins. Panel content scene document independent from layout rectangle. Duplicate/reorder/copy scene between panels without replacing master assets. Reading direction left-to-right or right-to-left stored per project/page.
## Tools
Layout presets (single panel, two horizontal/vertical, 2x2, asymmetrical), gutters, safe print margin, captions, speech/thought/shout/narration bubbles, tail anchor to character, text wrapping/font fit, border style. Irregular polygons and advanced trim bleed optional future items.
## Render
Editable page manifest, per-panel static PNG and full-page high resolution PNG; WebP and PDF optional after PNG quality gate. Text and effects should export at selected dimensions with correctly transformed coordinates. Project export includes dependency manifest.
## Acceptance
Four-panel page with two duplicated Arlo shots, one shared background crop at different framing, bubble text and foreground props. Reordering panels does not change poses. Full-page export has correct gutters/margins and matches editor preview.
