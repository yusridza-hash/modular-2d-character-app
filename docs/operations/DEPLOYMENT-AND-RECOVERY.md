# Operations — Comic App
Frontend React+TypeScript+Vite and Konva/react-konva, Zustand, Tailwind/shadcn; Python FastAPI service for segmentation, Pillow/OpenCV; Supabase Auth/Postgres/private Storage. Separate reliable worker/queue for long-running segmentation (in-process BackgroundTasks not durable). Optional local GPU worker or server worker with CPU fallback, cancellation, memory limits, explicit model version and job status. Avoid video/FFmpeg stack.
Dev: local web + local Python API + linked Supabase test environment; keep dev/prod data separate. Use versioned SQL migrations, RLS unit tests and restricted signed URLs. Never expose service credentials. Upload file validation and job resource constraints. Database backups and object-store backups both necessary; regularly test full restore including cross-references, image files, scene revisions. Portable project export/import is a recovery fallback. Track job failures, process times and storage quotas. OSS license audit must include model weights separately from source-code license.
