# Quality and Acceptance Gates
Tests: TypeScript unit tests for transforms/pivot/constraints/scene schema; backend pytest for job and image pipeline; browser E2E drag from library→canvas→pose→expression swap→blend→save/reopen→export; pixel/visual regression tests for contact, outlines, foreground occlusion, face angle and color; storage/auth/RLS checks; job failure/cancellation and reconnect recovery.
Golden fixtures: Arlo humanoid front/side, long hair/outfit, folded/occluded arms, two-character village panel, seated scene, foreground grass, neutral vs shocked eyes/mouth, different tone/backgrounds. Mark source licensing. Test manual correction, no invented anatomy, rig cycle rejection, missing asset, invalid pose/face variant, missing ground line.
MVP targets to validate on target hardware: editor interaction >=30 FPS on documented 1–3 character scene, canvas responds during drag, exported 1920x1080 PNG deterministic for same pinned document and engine version, 100% required references resolve before export, save/reopen no transform drift, face swap independent per instance. Record actual measurements, don't claim passed without test logs.
Each phase DoD requires executable proof, screenshots/test artifacts, passing relevant automated checks, documented limitations, and updated schema/migrations. Do not mark docs completion as feature completion.
